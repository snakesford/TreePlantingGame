# Planned tree data

Birch, Spruce, and Oak are available in gameplay. Use the Pine table when
adding Pine to the game.

Follow the existing four-upgrades-per-stage rule: each paid upgrade costs
the listed amount, and each automatic growth interval adds one upgrade.
Earnings are dollars per payout tick; growth intervals are in game days.
Mature is the final stage and cannot be upgraded or grow further.
Birch and Spruce use the existing $1 seed planting price. Oak seeds cost $3,
as requested. Pine seed planting prices have not been specified; the Seed upgrade cost is
the price of upgrading an already planted seed.
